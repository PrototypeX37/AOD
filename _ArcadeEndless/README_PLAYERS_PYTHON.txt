PYTHON EDITION (no .exe)
======================================================================

This download is the same app as plain Python source, for anyone who would
rather not run an .exe. Everything works the same; only installing differs:

1. Install Python 3 from https://www.python.org/downloads/ (the app was made
   and tested with Python 3.13). The standard installer has everything the
   app needs.
2. Optional, for the artwork in the app: open a command prompt and run
      py -m pip install pillow
   Without it the app works the same, just without the pictures.
3. Close the game and open the game folder (in Steam, right-click Age of
   Darkness: Final Stand > Manage > Browse local files). Extract this zip
   there. You should end up with two folders:
      ...\Age of Darkness - Final Stand\_ArcadeEndless\
      ...\Age of Darkness - Final Stand\_NightmarePOC\
4. Double-click _ArcadeEndless\ArcadeEndless.pyw. Wherever the guide below
   says ArcadeEndless.exe, use ArcadeEndless.pyw instead, and carry on from
   step 5 of INSTALL.
